# Element Anvil

**Element Anvil — неофициальный настольный редактор для 1С:Предприятие.Элемент Скрипт.** Независимый проект CosmosDevX; он не является продуктом фирмы «1С» и не представляет её официальную среду разработки.

Редактор открывает локальные проекты и помогает писать, запускать и отлаживать код. Текущая версия: **0.7.0**, платформа: Windows.

Собственный код — [MIT](LICENSE). О публикации и бесплатном распространении: [docs/publishing.md](docs/publishing.md). Изменения версии: [0.7.0](docs/releases/0.7.0.md).

## Возможности

- **Проекты и файлы:** открытие папок и отдельных файлов, создание, переименование, удаление в корзину и перетаскивание. Дерево обновляется при внешних изменениях. Есть шаблоны проекта Элемент и веб-приложения на основе [1C-Element-Web-Server](https://github.com/CosmosDevX/1C-Element-Web-Server).
- **Редактор:** подсветка синтаксиса, дополнения и диагностика через LSP Элемента, структура файла, миникарта, выбор шрифта, шесть тем, автосохранение и настраиваемые горячие клавиши. При закрытии несохранённого файла можно сохранить изменения, отказаться от сохранения или отменить выход.
- **Поиск и навигация:** поиск и замена в файле и по проекту, регулярные выражения, маски файлов и просмотр замен; поиск структур и методов, переход к определению и поиск использований.
- **Запуск и отладка:** запуск проекта или отдельного `.sbsl`, вывод, ошибки, точки останова, пошаговая отладка, стек и переменные. Встроенный терминал поддерживает PowerShell и executor.
- **Git и TODO:** основные операции Git, сравнение изменений и список заметок TODO/FIXME с переходом к коду.
- **HTTP-клиент:** коллекции и папки запросов, методы, параметры, заголовки, тело, заметка к коллекции и просмотр ответа.
- **Markdown и оформление:** просмотр форматированного Markdown, необязательные аномалии и пять встроенных шрифтов с кириллицей.

## Установка и первый запуск

1. Скачайте [версию 0.7.0 из GitHub Releases](https://github.com/CosmosDevX/UnexploredCodeEdtior/releases/tag/v0.7.0): `ElementAnvil-0.7.0-Portable.exe` запускается без установки; `ElementAnvil-0.7.0-Setup.exe` устанавливает приложение, регистрирует `.sbsl` и добавляет пункт открытия папки в Проводник. Файл `SHA256SUMS.txt` содержит контрольные суммы обоих EXE. Локальные сборки находятся в `release/`; эта папка не хранится в Git.
2. Для запуска кода, LSP и отладки отдельно установите [1С:Предприятие.Элемент Скрипт](https://1cmycloud.com/console/help/lang/docs/topics/install-1c-script-runtime-environment/) и совместимую Java. Java и компоненты 1С не входят в установщик Anvil. Открывать и редактировать текст можно без них, с базовой подсветкой и подсказками.
3. Запустите Anvil и откройте папку проекта или создайте проект на стартовом экране. При открытии отдельного файла его родительская папка становится проектом.

На Windows редактор ищет стандартную установку в каталогах `1C/1CE/components` внутри `%LOCALAPPDATA%` и `%ProgramFiles%`. Для нестандартного расположения задайте `ELEMENT_HOME` на корневую папку установки с каталогами `executor/` и `ide/`. Java ищется через `JAVA_HOME` или `PATH`. После изменения переменных перезапустите редактор. Для LSP и отладки необходимы соответствующие компоненты установленной среды разработки Элемента.

Исходники сохраняются в открытой папке проекта. Настройки и недавние проекты хранятся в `%APPDATA%/Undertow/state.json`; папка оставлена для совместимости с предыдущим названием редактора.

## Работа с проектом

### Шаблоны проектов

На стартовом экране в разделе «Новый проект» выберите шаблон, укажите название и родительскую папку. Редактор создаст отдельную папку проекта и откроет её.

- **1С:Элемент** — небольшой стартовый проект для скриптов. В нём есть точка входа `Скрипт.sbsl`, пример отдельного модуля `Модули/Приветствие.sbsl`, `unexplored.json`, README и `.gitignore`. Это удобная основа для знакомства с языком или самостоятельного проекта.
- **1С:Элемент · Веб-приложение** — проект на основе [1C-Element-Web-Server](https://github.com/CosmosDevX/1C-Element-Web-Server), веб-фреймворка CosmosDevX для 1С:Элемент Скрипт. Он содержит HTTP-сервер, роутер, регистрацию маршрутов и обработчиков, структуры запроса и ответа и примеры использования. **Фреймворк находится в активной разработке (in active development)**: это учебный прототип с ограниченной функциональностью, не предназначенный для production. Возможности и устройство могут меняться; актуальное описание и планы находятся в его репозитории.

Для веб-шаблона нужны Git в `PATH` и доступ к интернету: редактор клонирует актуальную версию репозитория фреймворка в новую папку. Это полноценный Git-клон; если в нём нет `unexplored.json`, редактор создаёт конфигурацию с точкой входа `Скрипт.sbsl`, режимом сервера и сведениями об исходном репозитории и коммите. Два проекта, созданные в разное время, могут получить разные версии фреймворка.

### Запуск проекта

Для обычного шаблона точка входа задана в `unexplored.json`:

```json
{
  "language": "sbsl",
  "entry": "Скрипт.sbsl"
}
```

`F5` запускает точку входа проекта; при её отсутствии — текущий `.sbsl`. Через отдельную кнопку «Запуск и отладка ▾» в панели редактора можно выбрать проект или текущий файл. Для веб-приложения сервер продолжает работать до остановки; его вывод доступен в панели редактора.

При внешнем изменении чистый открытый файл перечитывается. Если в буфере есть несохранённые изменения, редактор сохраняет их и приостанавливает автосохранение конфликтующего файла. При переносе файлов директивы импорта автоматически не переписываются.

| Действие                          | Сочетание по умолчанию            |
| --------------------------------- | --------------------------------- |
| Сохранить все файлы               | `Ctrl+S`                          |
| Поиск и замена в файле            | `Ctrl+F` / `Ctrl+H`               |
| Поиск / замена по проекту         | `Ctrl+Shift+F` / `Ctrl+Shift+R`   |
| Поиск структур и методов          | `Ctrl+I`                          |
| Определение / места использования | `Ctrl+F12` / `Shift+F12`          |
| Запуск / отладка                  | `F5` / `Ctrl+F5`                  |
| Остановить                        | `Shift+F5`                        |
| Проводник / вывод / терминал      | `Ctrl+B` / `Ctrl+J` / ``Ctrl+` `` |

Сочетания можно изменить в настройках. В поиске по проекту замена сначала показывается в diff; файлы можно выбрать по отдельности. Замены попадают в буферы редактора, и `Ctrl+Z` отменяет изменение в каждом файле. Поиск ограничен 2000 файлами, 16 МБ текста и 2000 совпадениями; при усечении замена блокируется до уточнения запроса.

HTTP-коллекция проекта хранится в `unexplored.http.json`; личная коллекция доступна со стартового экрана. Git требует установленный Git в `PATH`; Fetch, Pull и Push используют его обычную настройку авторизации. Подробнее об отладке — в [docs/debugging.md](docs/debugging.md).

## Разработка и сборка

Нужны Node.js 22 или новее, npm и Git. В каталоге клонированного репозитория:

```powershell
npm ci
npm start
```

Откроется настольное приложение Electron. Дополнительные команды:

```powershell
npm test                    # модульные тесты
npm run test:integration    # интеграционные проверки в отдельных проектах
npm run test:lsp            # проверка установленного LSP Элемента
npm run test:debug          # проверка отладчика Элемента
npm run test:terminal       # проверка терминала
npm run build:win           # portable и setup в release/
```

Проверки LSP, отладчика и реальные запуски требуют подходящей установленной среды. `npm run start:web` предназначен для разработки интерфейса: системные диалоги и другие настольные функции там ограничены. Исходники интерфейса находятся в `public/`, сервер и работа с проектами — в `lib/`, окно Electron — в `desktop/`. Устройство проекта описано в [docs/architecture.md](docs/architecture.md).

## Своя тема и изменение редактора

Собственный код Element Anvil распространяется по [лицензии MIT](LICENSE): его можно использовать, изменять, собирать и распространять, в том числе коммерчески, сохраняя уведомление об авторстве и текст лицензии. Сторонние компоненты сохраняют собственные лицензии: см. [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Среда 1С и Java устанавливаются отдельно; MIT не меняет условия их использования. Подробности — в [docs/distribution.md](docs/distribution.md).

Свободного редактора тем или загрузки темы из файла в версии 0.7.0 пока нет. Тему можно добавить в исходники:

1. Откройте `public/themes.js` и добавьте в объект `themes` новый ключ, например `myTheme`. Удобнее скопировать существующую тему и изменить её `name` и цвета. Цвета интерфейса `bg`, `panel`, `shell`, `widget`, `line`, `fg`, `muted`, `border`, `accent`, `accentBg`, `selection` задаются с `#`; цвета синтаксиса `keyword`, `string`, `number`, `comment`, `type` — шестнадцатеричными значениями без `#`. Для светлой темы добавьте `light: true`.
2. Запустите `npm start`. Кнопки тем создаются по данным из `themes.js`, поэтому новая тема появится в настройках автоматически. Выберите её и проверьте редактор, меню, терминал и контрастность; при необходимости дополните правила оформления в `public/shell.css` и связанных CSS-файлах.
3. Чтобы получить исполняемый файл с темой, выполните `npm run build:win` и используйте новую сборку. Изменение исходников не обновляет уже собранный EXE.

Пример добавляемой записи внутри объекта `themes`:

```js
myTheme: {
  name: "Моя тема",
  bg: "#171920", panel: "#20232b", shell: "#111319",
  widget: "#292d38", line: "#252a34", fg: "#e5e7eb",
  muted: "#a0a7b4", border: "#414856", accent: "#91c7ff",
  accentBg: "#293e58", selection: "#45608080",
  keyword: "91c7ff", string: "a7d7a5", number: "edc08a",
  comment: "89919e", type: "c6b5ed",
},
```

Иконки и их происхождение описаны в [docs/ui-icons.md](docs/ui-icons.md). Аномалии включаются отдельно в настройках и по умолчанию выключены.

Настройки разделены на вкладки «Оформление», «Редактор» и «Горячие клавиши». По умолчанию для каждой темы выбран свой набор иконок: графит — нейтральный, янтарь — янтарный, лес — зелёный, Vim — лаймовый, море — бирюзовый, конфигуратор — синий. В оформлении можно выбрать другую палитру вручную. Размер иконок настраивается от 70% до 130%, стандарт — 100%.

## Вкладки и панели редактора

Перетаскивайте вкладки мышью, чтобы изменить их порядок. Кнопки разделения влево и вправо открывают до четырёх панелей. Перетащите вкладку в нужную панель или выберите файл в её заголовке. Панели работают с общими текстовыми моделями: изменение одного файла видно во всех его представлениях. Закрытие панели не закрывает файл.

В меню рядом с кнопкой запуска выберите запуск или отладку проекта/текущего файла. Выбор сохраняется; основная кнопка выполняет выбранный режим.
