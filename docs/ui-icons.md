# Иконки интерфейса

Иконки используются как прозрачные маски и автоматически получают цвет выбранной темы. В настройках оформления можно выбрать другую палитру и размер 70–130%; 100% соответствует исходному размеру.

Основной набор находится в public/icons/. Значки pause, step-over, step-in и step-out добавлены в 0.7.0 с помощью OpenAI ImageGen. Значки отладки имеют компактные кнопки и подписи во всплывающих подсказках.
