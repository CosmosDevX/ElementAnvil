# Пользовательские темы

В Element Anvil 0.7.1 темы можно импортировать из JSON-файлов. Они меняют оформление окна, панелей, редактора кода, меню, подсказок и терминала. Цвет иконок применяется, когда в настройке «Цвет иконок» выбрано «По теме».

## Подключение

1. Откройте **Настройки → Оформление**.
2. Нажмите **«Импортировать тему…»** и выберите JSON-файл. Можно начать с [темы «Полночь»](../examples/themes/midnight.anvil-theme.json).
3. Тема появится рядом со встроенными и сразу применится. Дождитесь сообщения «Настройки сохранены».

Тема сохраняется в профиле редактора и остаётся доступной после перезапуска. Исходный JSON можно хранить отдельно или передать другому пользователю.

## Создание своей темы

Выберите ближайшую встроенную тему и нажмите **«Экспортировать текущую»**. Откройте сохранённый `.anvil-theme.json` в редакторе, измените `id`, `name` и нужные цвета, сохраните и импортируйте файл.

Минимальный пример:

```json
{
  "schemaVersion": 1,
  "id": "my-midnight",
  "name": "Моя полночь",
  "base": "dark",
  "colors": {
    "bg": "#0b1120",
    "fg": "#dbeafe",
    "accent": "#67e8f9",
    "keyword": "#7dd3fc",
    "selection": "#3b82f666"
  },
  "icons": {
    "color": "#67e8f9",
    "danger": "#fda4af"
  }
}
```

`schemaVersion` должен быть равен `1`. `id` — уникальное имя из строчных латинских букв, цифр и дефисов, до 64 символов, начиная с буквы. `name` — отображаемое название до 80 символов.

`base` задаёт встроенную основу: `dark`, `amber`, `forest`, `vim`, `ocean` или `enterprise`. Для светлого оформления используйте `enterprise`. Все неуказанные цвета наследуются от основы; объект `colors` может быть пустым.

| Поле в `colors` | Назначение |
| --- | --- |
| `bg` | Фон редактора и терминала |
| `shell` | Основной фон окна |
| `panel` | Панели и заголовки |
| `widget` | Меню, подсказки и всплывающие элементы |
| `line` | Текущая строка и фон наведения |
| `fg` | Основной текст |
| `muted` | Второстепенный текст и номера строк |
| `border` | Границы и направляющие |
| `accent` | Акцент, курсор, выделение активных элементов |
| `accentBg` | Фон акцентных элементов |
| `selection` | Выделение текста |
| `keyword` | Ключевые слова |
| `string` | Строки |
| `number` | Числа |
| `comment` | Комментарии |
| `type` | Типы и аннотации |

Цвета задаются как `#RRGGBB`, включая цвета синтаксиса. Только `selection` также принимает `#RRGGBBAA`, где последние две цифры задают прозрачность. Объект `icons` необязателен: `color` задаёт обычные иконки, `danger` — опасные действия. Без этих полей используются акцент темы и стандартный цвет опасных действий. Вручную выбранная палитра иконок имеет приоритет.

## Обновление и удаление

Повторный импорт с тем же `id` обновляет существующую тему. Чтобы оставить два варианта, задайте им разные `id`. Можно сохранить до 24 пользовательских тем, размер одного файла — до 64 КБ. JSON записывается без комментариев и лишних полей; при ошибке редактор покажет причину и сохранит текущую тему.

Для удаления выберите пользовательскую тему и нажмите **«Удалить тему»**. Редактор переключится на её встроенную основу. Исходный файл останется на диске. Встроенные темы не удаляются.

Импортированные определения хранятся вместе с настройками в `state.json`: `%APPDATA%/Undertow/` в Windows и `${XDG_CONFIG_HOME:-~/.config}/Undertow/` в Linux. Для обмена используйте экспорт отдельного JSON-файла: профиль также содержит личные настройки и пути проектов.
