# Element Anvil 0.7.0

Выпуск для Windows x64: Portable без установки и Setup с установкой. Контрольные суммы обоих EXE находятся в `SHA256SUMS.txt` среди файлов релиза.

- Перетаскивание вкладок и до четырёх панелей редактора, разделение влево/вправо.
- Сохранение выбранного режима запуска и отладки.
- Настройка размера иконок 70–130%, стандарт 100%.
- Новые компактные значки команд отладки.
- Синхронизация размеров терминала по кадрам и обновление его содержимого при resize.
- Исправлено обрезание подсказок кода, точек останова и кнопок поиска/замены панелью запуска; сохранены фон и цвета выбранной темы.
- Устранены ошибки загрузки Monaco worker и обновления размеров разделённых панелей.
- Очистка служебных документов и указание ИИ-помощника в CONTRIBUTORS.md.
