# Element Anvil 0.6.4

Выпуск 0.6.4 для Windows.

- Для каждой темы добавлен собственный цветовой набор прозрачных иконок. По умолчанию включён автоматический выбор по теме; ручные и неоновые палитры доступны в настройках.
- Настройки разделены на «Оформление», «Редактор» и «Горячие клавиши».
- Варианты запуска проекта, текущего файла и отладки вынесены в заметную кнопку «Запуск и отладка ▾».
- Исправлены наложение кнопок терминала, постоянный фон и квадратная рамка фокуса после Esc.
- Для настроек добавлен повтор атомарного сохранения при кратковременной блокировке файла Windows.
- Исправлена очистка ConPTY после завершения оболочки.
- Обновлён DOMPurify внутри Monaco; добавлена проверка встроенной скомпилированной копии перед сборкой.

Файлы: `ElementAnvil-0.6.4-Portable.exe`, `ElementAnvil-0.6.4-Setup.exe`, `SHA256SUMS.txt`.

Элемент Скрипт и Java устанавливаются отдельно. Исполняемые файлы не подписаны. Установка на чистой Windows отдельно не проверялась. Поиск использований LSP ранее давал единичный сбой при переиндексации; причина не локализована, хотя повторный пакетный прогон прошёл. Подробнее — [отчёт](../publication-audit.md).
