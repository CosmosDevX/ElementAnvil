# Element Anvil 0.7.1

- Пользовательские JSON-темы: импорт, экспорт текущего оформления, обновление по `id` и удаление из настроек. Тема сохраняется после перезапуска.
- Цвета интерфейса, кода, подсказок, терминала и иконок наследуются от выбранной встроенной основы. Неверный файл не меняет текущие настройки.
- Linux x64: AppImage без установки и установочный пакет `.deb` с нативным PTY. Исправлен поиск Java через `JAVA_HOME` в Linux; Bash получает команду `executor` при настроенной среде Элемента.
- Windows x64: Portable и Setup с теми же возможностями пользовательских тем.

В релиз включены четыре сборки и общий `SHA256SUMS.txt`. Инструкции: [пользовательские темы](https://github.com/CosmosDevX/UnexploredCodeEdtior/blob/v0.7.1/docs/custom-themes.md), [Linux](https://github.com/CosmosDevX/UnexploredCodeEdtior/blob/v0.7.1/docs/linux.md). Java и компоненты 1С устанавливаются отдельно.
