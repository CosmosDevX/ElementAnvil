# Element Anvil 0.6.3

Неофициальный редактор для 1С:Предприятие.Элемент Скрипт. Независимый проект CosmosDevX.

## Изменения

- Начальное окно очищено от кнопок HTTP-клиента и возврата к проекту. HTTP-клиент доступен в боковой панели и верхней кнопкой, если она включена в настройках.
- Оставшиеся старые иконки перегенерированы в едином плотном янтарном стиле.
- Значок запуска немного уменьшен.
- Поля поиска и замены Ctrl+F используют цвета выбранной темы.
- Из панели терминала убрана очистка; добавлены сгенерированные иконки создания и закрытия терминала.
- Для собственного кода добавлена лицензия MIT и сведения о лицензиях сторонних компонентов.

## Установка

- `ElementAnvil-0.6.3-Portable.exe` — запуск без установки.
- `ElementAnvil-0.6.3-Setup.exe` — установка в Windows x64 с интеграцией в Проводник.
- `SHA256SUMS.txt` — контрольные суммы загружаемых файлов.

Для запуска, LSP и отладки отдельно установите 1С:Предприятие.Элемент Скрипт и совместимую Java. Эти компоненты не входят в сборку. Для работы с Git необходим Git в системе. Подробнее — в README проекта.

Сборки не подписаны сертификатом подписи кода; Windows может показать предупреждение о неизвестном издателе.

Автоматические тесты для этого обновления не запускались по просьбе автора. Перед публикацией рекомендуется вручную просмотреть интерфейс и попробовать приложение на чистой Windows.
