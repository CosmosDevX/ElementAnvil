# Отладка 1С:Элемент в UnexploredEditor 0.4.0

Редактор использует штатный Java-адаптер DAP из установленного комплекта Элемента, а не Java/JDWP-отладку самого интерпретатора. Проверено на Элементе 10.0.4+21 и Java 17. Компоненты 1С в сборки редактора не включаются.

## Доступно в редакторе

| Функция                                    | Управление                                   |
| ------------------------------------------ | -------------------------------------------- |
| Запуск с остановкой на входе               | «Отладка» или Ctrl+F5                        |
| Точка останова по строке                   | F9 или нажатие в поле слева от номера строки |
| Продолжение                                | ▶ или Ctrl+F5                                |
| Пауза выполняющегося скрипта               | Ⅱ                                            |
| Шаг с обходом                              | F10                                          |
| Шаг с заходом в метод                      | F11                                          |
| Шаг с выходом из метода                    | Shift+F11                                    |
| Стек вызовов и выбор кадра                 | Панель «Отладка»                             |
| Локальные переменные и раскрытие объектов  | Раздел «Переменные»                          |
| Вычисление выражений в выбранном кадре     | Раздел «Наблюдение»                          |
| Выбор потока                               | Список над стеком                            |
| Завершение с остановкой дочерних процессов | ■ или Shift+F5                               |

F5 сохраняет прежнее действие — обычный запуск без отладки. Перед отладкой редактор сохраняет файлы и делает отдельный снимок проекта. Во время сеанса редактирование кода заблокировано: строки на экране соответствуют исполняемому снимку. После остановки редактирование возвращается. Точки останова и выражения хранятся в текущем окне до смены проекта. Переменные и выражения доступны только на паузе. Выражения вычисляет сам Элемент; вызов метода в выражении может иметь побочные эффекты.

Проверены: подключение, остановка на входе, подтверждение точки останова, продолжение, три вида шага, пауза работающего цикла, получение стека/локальных переменных, вычисление выражений, вывод `42` и освобождение процессов после завершения. Внешнее подключение к произвольному серверу и редактирование значений переменных в интерфейсе этой версии не реализованы.

## Что ещё объявляет адаптер 10.0.4

При DAP initialize установленный адаптер дополнительно объявляет условные точки останова, счётчик срабатываний, функциональные точки останова, логпоинты, изменение переменной и фильтры исключений. Это возможности адаптера; отдельных элементов управления ими в 0.4.0 пока нет. Их наличие не означает, что они проверены в редакторе.

Адаптер явно не объявляет шаг назад, перезапуск кадра и сеанса, переход к произвольной строке, список модулей и `exceptionInfo`. Обратное выполнение в интерфейсе отсутствует. Возможности могут отличаться у другой установленной версии Элемента.

## Проверки для разработки

`npm run test:debug` запускает изолированные скрипты и настоящий штатный адаптер. Нужны установленные Элемент и Java; проверка открывает только локальный порт и останавливает созданные ею процессы.

Источники: установленное расширение `@1c-executor-plugin` (`debugAdapterUtils`, `ScriptExecutorDebugConfigurationProvider`, `ScriptExecutorDebugAdapterDescriptorFactory`) и DAP-ответ `initialize` собственного тестового сеанса. Установленные файлы не изменяются.

- [Debug Adapter Protocol](https://microsoft.github.io/debug-adapter-protocol/).
