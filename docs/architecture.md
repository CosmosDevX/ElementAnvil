# Element Anvil 0.6.1

## Границы ответственности

- `lib/project-paths.mjs` — единая проверка относительных путей и служебных каталогов. `ProjectManager.resolve` проверяет реальные пути и запрещает junction/symlink.
- `lib/project-entries.mjs` — общий перенос/переименование, защита от коллизий, обновление entry. `ProjectManager` отвечает за открытый проект, сохранения и настройки.
- `lib/project-watcher.mjs` — события ОС, инкрементальная проверка метаданных при изменении содержимого и снимок метаданных при создании/удалении/переносе. Содержимое файлов для сравнения дерева не читается. Без поддержки recursive watch применяется резервная проверка раз в четыре секунды. Журнал ограничен 64 пакетами событий; пропущенный журнал приводит к обновлению дерева.
- `lib/project-snapshot.mjs` — изолированные снимки запуска и ограниченная очистка только созданных директорий `run-*`/`debug-*` внутри runtime. Обычные запуски очищаются в finally, debug-снимки — после закрытия процесса.
- `lib/element-navigation.mjs` — безопасное разрешение импортов; семантические определения и ссылки остаются ответственностью нативного LSP. Перед первым references готовность семантической модели подтверждается свежей диагностикой либо непустым native hover: Элемент не всегда публикует пустую диагностику корректного модуля.
- `public/project-explorer.js`, `explorer-drag.js`, `project-sync.js` — отображение дерева, перенос жестом и потребление файлового журнала. Положение прокрутки сохраняется; обычное сохранение текста не перестраивает дерево.
- `public/git-diff.js` — Monaco DiffEditor в рабочей области вкладки Git. Модели освобождаются при смене сравниваемого файла/проекта; просмотр не сохраняет рабочие буферы. Кнопка «К коду» возвращает обычный редактор.
- `lib/process-tree.mjs` — завершение только принадлежащего редактору процесса и его потомков. На Windows используется taskkill с PID, /T, /F и shell:false. Закрытие терминала ожидает завершения дерева PowerShell/executor перед удалением сессии; остановка программы обслуживает обычный запуск и отладку, включая отмену подготовки запуска.
- `public/terminal-panel.js` — xterm и последовательная очередь изменений геометрии/ввода. Размер PTY совпадает с размером xterm, в том числе в панелях высотой в одну-две строки; resize ограничен по частоте.
- `lib/version.mjs` — версия из package.json для API и LSP.
- `public/document-sync.js` — различение собственной записи, настоящего внешнего изменения и конфликта. Совпадающее содержимое не меняет Monaco-модель; внешняя замена сохраняет undo. Во время переноса в корзину сохранение удаляемого файла блокируется до закрытия модели.
- `public/element-completions.js` — дополнение неявных членов текущей структуры по несохранённому буферу. Нативный LSP остаётся источником типов внешних объектов.
- `public/workspace-views.js` — единое переключение пяти боковых панелей и рабочих областей кода, Git и HTTP. Модели Monaco и форма запроса остаются смонтированы, поэтому переключение сохраняет Undo, ввод и ответ сервера.
- `public/http-view.js` — разметка HTTP-клиента; `http-client.js` — взаимодействие с формой и отправка запросов; `http-collection-store.js` — хранение без DOM. Сохранения идут последовательно со снимком коллекции и исходным projectId. Счётчик загрузок отбрасывает запоздалый ответ другого проекта; ошибка записи остаётся доступна для повторного сохранения.
- `desktop/open-targets.mjs` — разбор файлов и флага `--open-folder` при старте и повторном запуске. `build/installer.nsh` регистрирует меню папки и её фона в HKCU; удаление приложения снимает только команды, указывающие на его каталог установки. Отмена перехода с несохранённым кодом убирает ожидающую команду без повторных диалогов.

Локальный API сохраняет проверки Host, Origin, токена сессии и идентификатора проекта. Наблюдение не выполняет запись файлов. При внешних конфликтах несохранённый текст не заменяется и автоматическая запись приостанавливается.

## Состав Windows-пакета

`desktop/window-close.mjs` реализует явный протокол выхода: prepare → решение пользователя → save/ack либо cancel. Renderer приостанавливает автосохранения и дожидается начатых операций. Ошибка сохранения и устаревшие IPC-подтверждения не разрешают закрытие; browser beforeunload остаётся резервной защитой.

`lib/text-search.mjs` собирает ограниченный снимок UTF-8-файлов с несохранёнными буферами. `text-search-worker.mjs` ищет и строит изменения в worker с тайм-аутом для сложных regex. Preview не пишет на диск. Перед применением проверяются версии диска и буферов, изменения попадают в undo-историю Monaco; первые сохранения защищены SHA-256-проверкой исходного файла в очереди ProjectManager.save. `public/fulltext-search.js` отвечает за поиск, выбор файлов и diff.

Пределы: 2000 файлов / 16 МБ на поиск, 2000 совпадений, 1 МБ на файл и на набор несохранённых буферов, 1500 мс выполнения worker. Служебные каталоги, бинарные и невалидные UTF-8-файлы пропускаются. Замена при усечённом результате запрещена, чтобы неполный просмотр не выглядел заменой во всём проекте.

Electron, локальный API, браузерная сборка Monaco, публичные ресурсы и исполняемые зависимости. xterm уже собран в `public/terminal-vendor`, поэтому его исходные npm-пакеты в приложение повторно не включаются. Удалены из дистрибутива ESM/dev/source maps Monaco, TS/отладочные символы, исходники и build-файлы node-pty, бинарные файлы нецелевых платформ и заголовки node-addon-api. В node-pty остаются JS, лицензия и N-API prebuild для win32-x64; native-файлы распаковываются из ASAR.

Включено сжатие maximum, оставлены локали Electron en-US и ru. Сборка не включает установленную Java или среду Элемента: они обнаруживаются отдельно. Проверка готового пакета должна загружать native PTY именно из ASAR и запускать реальный executor, чтобы сокращение зависимостей не маскировало отсутствие необходимых файлов.
