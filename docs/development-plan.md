# Направления развития Element Anvil

Поиск по проекту, Git, отладка, точки останова и профили запуска уже есть в [официальной IDE Элемента](https://1cmycloud.com/console/help/lang/docs/topics/script-ide-overview-and-basic-actions/). Официальная документация также описывает [аргументы запуска, подключение отладчика, стек и переменные](https://1cmycloud.com/console/help/lang/docs/topics/start-debugging/). Само наличие этих функций не является отличием Anvil.

Дальше предлагается развивать удобство работы с веб-фреймворком пользователя. Это предложения, а не реализованные возможности или измеренное превосходство над официальной IDE.

| Приоритет | Возможность                                                                               | Как проверить результат                                                                                                                              |
| --------- | ----------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1         | Сценарии HTTP: проверка статуса и JSON, переменные окружений, последовательности запросов | Коллекция запускается целиком, показывает успешные и неуспешные проверки и экспортирует отчёт для CI; секреты не попадают в Git                      |
| 2         | Связь запроса с маршрутом фреймворка и отладчиком                                         | Из запроса можно перейти к обработчику, поставить точку останова, запустить сервер и получить ответ в той же рабочей области                         |
| 3         | Импорт OpenAPI в коллекцию HTTP и заготовки типов                                         | Операции, параметры и JSON-тела из спецификации превращаются в редактируемые запросы; существующие файлы не перезаписываются без выбора пользователя |
| 4         | Обозреватель тестов и профили запуска                                                     | Отдельный тест/набор запускается из дерева, ошибка открывает строку кода; профиль хранит entry, аргументы, SDK и JDK                                 |

Техническая основа текущего обновления: единое переключение панелей, отдельное хранилище HTTP-коллекций с тестами гонок сохранения и загрузки, отдельный разбор команд Проводника. Следующие крупные изменения стоит строить отдельными контроллерами и сервисами, не расширяя центральный workbench.js.
