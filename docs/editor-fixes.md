# Исправления редактора 0.5.0

## Сохранение, Ctrl+Z и подсказки

Наблюдатель диска получал событие от собственного сохранения редактора и повторно вызывал Monaco `setValue` с тем же текстом. Этот вызов сбрасывает undo/redo и закрывает текущие подсказки. Кроме того, синхронизация включала readOnly даже для обычного изменения содержимого.

Теперь совпадающий текст и подтверждённая предыдущая запись не меняют модель. При чтении диска повторно проверяется актуальный буфер: новые локальные правки не заменяются. Настоящее внешнее изменение чистого файла применяется через `pushEditOperations`, сохраняя возможность отмены. readOnly используется только во время перемещения моделей, а не на каждом уведомлении о записи.

## Члены структуры

На установленном LSP Элемента 10.0.4+21 воспроизведено: после `этот.` возвращаются поле и методы структуры, после `Доб` внутри метода той же структуры сервер возвращает пустой список. У типизированного поля `Вложенный.` нативный LSP возвращает его свойства и методы.

Клиент дополняет нативный ответ объявлениями текущей лексической структуры для неявного получателя и `этот.`. Сигнатуры берутся из текущего буфера, включая несохранённый код; дубли нативных подсказок удаляются, скобки существующего вызова не вставляются повторно. Члены других объектов не подмешиваются. Типы внешних модулей по-прежнему анализирует нативный LSP. Клиент передаёт корректный triggerKind/triggerCharacter и отбрасывает ответы для устаревшей версии документа.

## Контекстное меню

Monaco 0.57 создаёт меню в Shadow DOM за пределами `.monaco-editor`. У standalone-сборки отсутствовали переменные `--vscode-menu-*` на этом узле, поэтому текст наследовал чёрный цвет. Цвета меню задаются переменными на корне документа и наследуются Shadow DOM при каждой смене темы. Проверены все шесть тем.

## Удаление и иконки

ПКМ по файлу → «Удалить…» → «В корзину». Приложение использует Electron `shell.trashItem`; постоянного удаления нет. Проверяются границы проекта, актуальный projectId и отсутствие запуска/отладки/Git-операции. Удалённая вкладка закрывается без повторного сохранения; entry удалённого скрипта очищается. Папки этим действием не удаляются.

Папка, файл Элемента и HTTP используют контурные SVG на одной сетке, с одинаковой толщиной линии, цветом и скруглениями.
